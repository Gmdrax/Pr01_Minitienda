# **🛒 Pr01\_Minitienda**

Una aplicación ligera desarrollada en **JavaScript** para la gestión de productos y ventas en una pequeña tienda. Este proyecto se enfoca en la manipulación del DOM y lógica de negocio para procesos de compra sencillos.

## **🚀 Características**

* **Gestión de Inventario:** Listado dinámico de productos.  
* **Carrito de Compras:** Añadir, eliminar y actualizar cantidades de artículos.  
* **Cálculos en tiempo real:** Gestión de totales y desglose de precios.  
* **Interfaz Dinámica:** Experiencia fluida sin recargas de página (SPA Style).

## **🛠️ Tecnologías**

* **Lenguaje:** JavaScript (ES6+)  
* **Maquetación:** HTML5 & CSS3  
* **Entorno:** Navegador Web / Local Server
